# About Her 

## What is this website about?
This website started as a personal page but now it has became a website that talks about people close to me and my coding journey!

## Why did i even make this website?
I made this website because Hackclub was intoduced to me by my brother, at first I only just wanted to learn code for Hackclub events. Now that I have had more time to try out coding I'm starting to genuinely enjoy it so I'm glad I tried it out!

## About My pages
**Homapage** : My homepage is the start to my website! It includes a small introduction and a interactive legend that helps you understand how my website works!

**About Jaivika** : This page is about my little sister! You can learn what she likes, her goals, what she looks forward to and what she's currently been up to!

**The Coding Garden** : This page is about my coding journey, you can learn about my thoughts on the code I have learnt and how it's going with learning code like HTML, CSS, and JS!

**Garden Journal** : The Garden Journal is basically a record Of whats happening when im coding! It talks about what I have learnt and made with my thoughts about it! 

## What highlights my website?
I think what highlights my website is that it's **Interactive**! On my pages, there is always one thing you can interact with so you feel a part of the experience! You're able to click buttons and cards, hover over images that show an effect and even a special little flower you can grow yourself on my **The Coding Garden** page!
